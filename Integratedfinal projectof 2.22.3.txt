
Project360 — Final Integrated Prompt (Single Navbar + Promotions Module)
======================================================================

Objective
---------
Build a **single, integrated React (Vite) project** for a retail loyalty program (Project360) that combines:
1) The **original premium Project360 UI** (Dashboard, Offers, Redeem, Redemptions, Transactions)
2) The **Reward360 Promotions module** (Promotions List, Promotion Detail, Create Promotion)

**One global navbar** must be used across the entire application (no second navbar). Clicking **Promotions** navigates to the promotions module. When a campaign is created, it **immediately appears on the single Offers page**. Use **in-memory data with optional localStorage persistence**; no backend required.

Tech Stack
---------
- **React** (functional components + hooks), **Vite** build
- **React Router v6** (BrowserRouter) for routing
- **Tailwind CSS** for layout and components (cards, grids, buttons)
- **MUI libraries included only for component parity**: `@mui/material`, `@emotion/react`, `@emotion/styled` (do **not** render a second navbar; keep MUI AppBar file for reference)

Routing
-------
Use **BrowserRouter** (`react-router-dom@6`). Define these routes inside `<Routes>`:
- `/` → redirect to `/dashboard`
- `/dashboard` → Dashboard
- `/offers` → Offers (the **only** offers page)
- `/redeem/:promoId` → Redeem
- `/redemptions` → Redemptions
- `/transactions` → Transactions
- **Promotions module**:
  - `/promotions` → Promotions (List screen)
  - `/promotions/:id` → Promotion Detail
  - `/promotions/create` → Create Promotion (campaign generator)

Global Navbar (Header.jsx)
--------------------------
Render **one** navbar (top header) everywhere with these links in order:
1) Dashboard → `/dashboard`
2) Offers → `/offers`
3) Transactions → `/transactions`
4) Redemptions → `/redemptions`
5) Promotions → `/promotions`

> Do **not** render the module MUI AppBar (`NavBar.jsx`) in any page. Keep the file in repo for parity; use only the global header.

Data Model (in-memory + optional persistence)
---------------------------------------------
**Promotion / Offer** (rendered by Offers and Promotions):
```ts
{
  id: string,              // PromoID (unique)
  title: string,           // Offer title
  description: string,     // Offer description
  image: string,           // URL or object URL (file preview)
  cost: number,            // points cost to redeem
  discountType?: 'Percentage' | 'Fixed Amount' | 'BOGO' | 'Free Shipping' | 'Tier-based',
  startDate?: 'yyyy-mm-dd',
  endDate?: 'yyyy-mm-dd',
  tierOnly?: boolean
}
```

**Transaction** (demo):
```ts
{
  id: string,
  type: 'CLAIM' | 'REDEMPTION',
  points: number,          // positive for earn, negative for redeem
  date: 'yyyy-mm-dd',
  expiry?: 'yyyy-mm-dd' | null,
  note?: string,
  store?: string
}
```

State Management (CustomerContext.jsx)
--------------------------------------
- `customer`: basic member info
- `promotions`: array of offers; **hydrate** from seeds + `localStorage['p360_promotions']`
- `transactions`: array of transactions (claims + redemptions); persist to `localStorage['p360_transactions']`
- `redeemedPromoIds`: IDs of already redeemed promos; persist to `localStorage['p360_redeemed']`

Derived values:
- `remainingPoints`: sum of `transactions[].points`
- `todayPoints`: earned points for today
- `redeemedTotal`: total redeemed (absolute value of negative points)

Actions:
- `addPromotion(offer)`: prepend the new campaign to `promotions` and persist to `localStorage['p360_promotions']`
- `claimActivity({ id, points, note, store })`: add a positive points transaction
- `canRedeem(promo)`: `remainingPoints >= promo.cost` and promo not already redeemed
- `redeem(promo, store='Online')`: add a negative points transaction, add to `redeemedPromoIds`, and save a simple receipt to `localStorage['p360_redemptions']`

Promotions Module — Screens & Validation
---------------------------------------
1) **Promotions List** (`/promotions`)
   - Responsive grid (3 → 2 → 1) of **cards**: cover image, **discount type badge** (teal/indigo), description/title, **ID**, **duration** (`startDate → endDate`).
   - “View Details” button navigates to **`/promotions/:id`**.

2) **Promotion Detail** (`/promotions/:id`)
   - Banner image with **gradient overlay**, **discount type badge**, title.
   - Labeled rows: `PromoID`, `DiscountType`, `StartDate`, `EndDate`, `Description`.
   - Buttons: **Back to List** → `/promotions`, **Go to Offers** → `/offers`.

3) **Create Promotion** (`/promotions/create`)
   - Form fields: **PromoID (text)**, **Title (text)**, **Description (text)**, **DiscountType (select)**, **Points Cost (number)**, **StartDate (date)**, **EndDate (date)**, **Image URL (text)**, optional **file upload** with preview (`URL.createObjectURL`).
   - **Validation**:
     - Required: `PromoID`, `Title`, `Description`, `StartDate`, `EndDate`, `Points Cost (>0)`
     - **Unique `PromoID`** (check against current promotions)
     - `EndDate` must be **after** `StartDate`
   - On submit: **prepend** to `promotions` via `addPromotion(offer)`, **redirect** to `/offers`.
   - Reset clears inputs and preview.

Offers Page (Single)
--------------------
- Lists the **same `promotions` array** (seeds + created campaigns).
- Cards use `RewardCard.jsx`; clicking **Redeem** runs `canRedeem` guard and navigates to `/redeem/:promoId`.

Redeem Flow
-----------
- `/redeem/:promoId` shows: title, description, **Cost vs Your Balance**, store selection.
- Confirm adds a negative points transaction, marks promo redeemed, stores a simple receipt (`localStorage['p360_redemptions']`).
- On success, alert and navigate to **Redemptions** or **Offers**.

Transactions & Redemptions Pages
--------------------------------
- **Transactions**: table of all current transactions; top metrics: remaining points, total transactions.
- **Redemptions**: front-end demo page; a note that history can be persisted (optional).
